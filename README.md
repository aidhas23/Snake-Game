# Snake-Game
SEW Projekt - Snake Spiel in Java

## Beschreibung
Ein klassisches Snake-Spiel entwickelt in Java mit Swing Grafik.
Die Schlange frisst Essen, wächst und wird schneller.
Bei Kollision mit der Wand oder sich selbst ist das Spiel vorbei.

## Funktionen
- Klassisches Snake Gameplay
- Normales Essen (+10 Punkte)
- Bonus-Essen (+30 Punkte)
- Easy und Hard Modus
- Punkteanzeige

## Technologien
- Java
- Java Swing (Grafik)
